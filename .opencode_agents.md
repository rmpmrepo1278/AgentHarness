## FIRST STEP (mandatory, always)
Run ONE of these before reading any files or writing any code:

  crgctx                    # Quick CRG context for ~/.hermes
  crgctx agentharness       # For agentharness repo
  crgctx /path/to/repo      # For any other repo

This dumps: repo stats, top dead-code candidates, architecture overview,
and suggests which CRG MCP tool to call next.

## Why
CRG's 27 MCP tools provide symbol-accurate queries in <100 tokens.
Reading files directly costs 500-5000 tokens per file.
CRG-first saves ~90-99% token spend on code understanding.

## Available CRG MCP tools (via gateway stdio)
Tool categories: blast radius, flow analysis, semantic search,
architecture, dead-code detection, refactoring, cross-repo search.

Key tools to call after `crgctx`:
  - query_graph_tool("symbol")      — callers/callees/imports
  - get_impact_radius_tool("sym")   — blast radius before editing
  - get_architecture_overview_tool()— module boundaries
  - refactor_tool(mode="dead_code") — safe cleanup
  - semantic_search_tool("query")   — find by intent
